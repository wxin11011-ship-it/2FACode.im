# Security Policy

2FACode handles authentication material in the browser, so reports must never contain a real TOTP secret, live code, password, recovery code, session token, or other credential.

## Reporting a vulnerability

Report suspected vulnerabilities privately through [GitHub Private Vulnerability Reporting](https://github.com/wxin11011-ship-it/2FACode.im/security/advisories/new).

Include the affected version or commit, reproduction steps using test-only credentials, the expected behavior, and the observed impact. Do not open a public issue for an unpatched vulnerability.

For non-sensitive bugs and questions, use [GitHub Issues](https://github.com/wxin11011-ship-it/2FACode.im/issues).
